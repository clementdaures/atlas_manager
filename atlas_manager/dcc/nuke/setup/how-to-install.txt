- Locate the startup scripts folder
        Check the following link to locate the folder for different operating systems:
        https://learn.foundry.com/nuke/developers/63/pythondevguide/startup.html

        Hint: You can also find the folders by running the following command in the Nuke script editor:
        nuke.pluginPath()

- open (or create) init.py and add the following lines:

# Atlas Manager [Start]
import sys
atlas_path = "PATH//TO//PARENT//FOLDER//OF//ATLASMANAGER//"
if not atlas_path in sys.path:
    sys.path.append(atlas_path)
# Atlas Manager [End]

- Copy all png files under the atlas_manager/dcc/maya/setup folder to the nuke startup scripts folder

- open (or create) menu.py and add the following lines:

# Atlas Manager [Start]
toolbar = nuke.menu('Nodes')
smMenu = toolbar.addMenu('SceneManager', icon='atlas_main_ui.png')
smMenu.addCommand('Main UI', "from atlas_manager.ui import main\ntui = main.launch(dcc='Nuke')", icon='atlas_main_ui.png')
smMenu.addCommand('New Version', "from atlas_manager.ui import main\ntui = main.launch(dcc='Nuke', dont_show=True)\ntui.on_new_version()", icon='atlas_new_version.png')
smMenu.addCommand('Publish', "from atlas_manager.ui import main\ntui = main.launch(dcc='Nuke', dont_show=True)\ntui.on_publish_scene()", icon='atlas_publish.png')
# Atlas Manager [End]

- Restart Nuke
