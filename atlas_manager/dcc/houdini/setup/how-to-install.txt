Atlas Manager Houdini Installation Guide

- Add following lines to 456.py under scripts in HOUDINI_PATH. If there is no 456.py file, create it.
        Default Windows location is %programfiles%\Side Effects Software\<HOUDINI VERSION>\houdini\scripts
        or
        %UserProfile%\Documents\<HOUDINI VERSION>\scripts

# Atlas Manager [Start]
import sys
atlas_path = "PATH//TO//PARENT//FOLDER//OF//ATLASMANAGER//"
if not atlas_path in sys.path:
    sys.path.append(atlas_path)
# Atlas Manager [End]

- Replace the "PATH//TO//PARENT//FOLDER//OF//ATLASMANAGER//" with the path of where the atlas_manager folder is. Use double BACK Slashes between folder names

- Restart Houdini
- Run the following command from python shell:
import atlas_manager
atlas_manager.initialize("houdini")
from atlas_manager.dcc.houdini import setup

- Click the + button at the end of the shelf set. From dropdown menu select Shelves and check “Atlas Manager”
